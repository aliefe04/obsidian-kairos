# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The short version, which is not a substitute for the full text:

## Our pledge

We want participation in this project to be free of harassment for everyone, regardless of age, body
size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity
and orientation.

## Expected behaviour

- Be direct about the code and kind about the person.
- Accept that a maintainer may decline a change, and ask for the reason if it is unclear.
- Give technical reasons. "This is how other projects do it" is not a reason.
- Assume a bug report is honest. Most defects in this class of plugin depend on the reporter's note
  layout, so ask for the reproduction instead of doubting the report.

## Unacceptable behaviour

- Insults, personal or political attacks, and sustained disruption.
- Sexual attention or advances of any kind.
- Publishing someone's private information without permission.
- Dismissing a report of a missed or duplicated alert without investigating it.

## Enforcement

Report unacceptable behaviour privately to the maintainer: open a private report through
<https://github.com/aliefe04/obsidian-kairos/security/advisories/new>, or contact the maintainer
through their GitHub profile. Reports are handled privately.

Maintainers will remove, edit or reject comments, commits, code and issues that do not follow this
code, and will explain the reason. A maintainer who does not follow the code may be removed from the
project by the other maintainers.
